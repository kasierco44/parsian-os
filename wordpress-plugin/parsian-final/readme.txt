هسته مرکزی PARSIAN FINAL برای کسب‌وکار پارسیان قطعه.

== نصب آزمایشی ==
1. پوشه parsian-final را در مسیر wp-content/plugins قرار دهید.
2. افزونه PARSIAN FINAL Core را از پیشخوان فعال کنید.
3. مسیر سلامت API را بررسی کنید: /wp-json/parsian-final/v1/health
4. مسیر /wp-json/parsian-final/v1/me فقط برای کاربر واردشده در دسترس است.

== نکات امنیتی ==
- دسترسی‌ها در سمت سرور و با capability بررسی می‌شوند.
- اطلاعات مالی و عملیات حساس در این نسخه هنوز پیاده‌سازی نشده‌اند.
- غیرفعال‌سازی افزونه داده‌ها یا جدول‌ها را حذف نمی‌کند.
- این نسخه پایه توسعه است و برای استفاده عملیاتی/تولیدی تأیید نشده است.
