# پنل مالی تأمین‌کنندگان PARSIAN OS

این پوشه رابط وب فارسی و واکنش‌گرای مدیر و حسابدار برای ثبت بدهی تأمین‌کننده، پرداخت نقدی/بانکی/چکی، تقویم سررسید، دفتر تفصیلی و پیش‌بینی خروجی نقدی را نگهداری می‌کند.

## پیش‌نیازها

- Backend همین شاخه، شامل APIهای `/api/v1/suppliers/*` و فیلدهای `role_codes` در `GET /api/v1/auth/me`.
- PostgreSQL با اجرای موفق `alembic upgrade head`.
- دسترسی شبکه مرورگر به API و تنظیم صحیح `CORS_ORIGINS`.
- در محیط عملیاتی فقط HTTPS استفاده شود.

## اجرای محلی رابط

از ریشه مخزن:

```bash
python -m http.server 8088 --directory admin-finance
```

سپس `http://localhost:8088` را باز کنید و نشانی ریشه API را وارد کنید؛ برای نمونه `http://localhost:8000`. برنامه مسیر `/api/v1` را خودش اضافه می‌کند.

## انتشار

محتویات این پوشه را روی وب‌سرور استاتیک یا reverse proxy منتشر کنید. نشانی دامنه رابط را به `CORS_ORIGINS` در Backend اضافه کنید. این پوشه به‌تنهایی API یا پایگاه داده ایجاد نمی‌کند و جایگزین استقرار Backend نیست.

## امنیت و نقش‌ها

- توکن ورود فقط در `sessionStorage` همان تب نگهداری و هنگام خروج پاک می‌شود.
- رابط، نقش را از `/auth/me` می‌خواند؛ کنترل نهایی مجوزها همچنان در Backend انجام می‌شود.
- ثبت مانده افتتاحیه فقط برای مدیر نمایش داده می‌شود و API نیز مدیر را الزام می‌کند.
- کلید `Idempotency-Key` برای هر ثبت بدهی و پرداخت تولید می‌شود.
- از قرار دادن این پنل روی HTTP عمومی یا دامنه بدون TLS خودداری کنید.

## عملیات پوشش‌داده‌شده

- ثبت تأمین‌کننده
- ثبت بدهی و فاکتور و سرفصل حساب بدهکار
- ثبت مانده افتتاحیه با سررسید (مدیر)
- پرداخت نقدی، انتقال بانکی و صدور چک
- ثبت پاس‌شدن یا برگشت چک
- فهرست و تقویم سررسید بدهی و چک
- دفتر تفصیلی با مانده ابتدای/پایان دوره
- نمودار گردش تاریخی صندوق/بانک و پیش‌بینی پرداخت‌های ثبت‌شده

## واحد مبلغ

مبالغ به‌صورت عدد صحیح خام API نمایش داده می‌شوند. پیش از انتشار، واحد مبلغ مورد استفاده در داده‌های مالی شرکت (ریال یا تومان) باید در تنظیمات و رویه عملیاتی یکسان‌سازی شود. این رابط واحد پول را حدس نمی‌زند.
