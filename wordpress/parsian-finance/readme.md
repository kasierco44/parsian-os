# PARSIAN OS Finance WordPress Plugin

نسخه اولیه افزونه مالی پارسیان برای محیط آزمایشی وردپرس.

## نصب
1. از فایل‌ها و دیتابیس سایت نسخه پشتیبان کامل بگیرید.
2. پوشه `parsian-finance` را در `wp-content/plugins/` قرار دهید یا ZIP افزونه را از پیشخوان بارگذاری کنید.
3. افزونه را فعال کنید؛ جداول اختصاصی ساخته و دو نقش «مدیر مالی پارسیان» و «حسابدار پارسیان» اضافه می‌شود.
4. در کاربران وردپرس، برای دو حساب آزمایشی نقش مناسب تعیین کنید.
5. پنل از منوی «مالی پارسیان» در پیشخوان در دسترس است.

## مجوزها
- مدیر مالی: مشاهده و ثبت تأمین‌کننده، بدهی، پرداخت و مانده افتتاحیه.
- حسابدار: مشاهده و ثبت تأمین‌کننده، بدهی و پرداخت؛ ثبت مانده افتتاحیه ممنوع.
- سایر کاربران: بدون مجوز API.

## نسخه 0.1.0
ثبت تأمین‌کننده، بدهی/مانده افتتاحیه، پرداخت نقدی و بانکی، چک پرداختنی، پاس/برگشت چک، داشبورد جمع بدهی و پرداخت. مبالغ به ریال و تاریخ API میلادی است.

## محدودیت‌ها
این نسخه هنوز دفترکل دوبل کامل، دفتر معین تفصیلی، نمودار جریان نقدی، تاریخ شمسی، تست خودکار و تست end-to-end ندارد. مانده بدهی برابر مجموع اسناد بدهی منهای پرداخت‌های قطعی محاسبه می‌شود؛ چک صادرشده تا زمان پاس‌شدن پرداخت قطعی نیست. قبل از استفاده عملیاتی، تست امنیتی و مالی و بازیابی backup الزامی است.


## پل احراز هویت Backend (نسخه آزمایشی)

این افزونه اکنون می‌تواند ورود مدیر/حسابدار وردپرس را به‌تنهایی کافی نداند و یک ورود مستقل به حساب PARSIAN OS Backend نیز مطالبه کند. نام کاربری و رمز Backend از مسیر REST وردپرس به PHP ارسال و از سمت سرور به `/auth/login` منتقل می‌شود؛ توکن Bearer در مرورگر JavaScript نمایش داده نمی‌شود و در transient سمت سرور، متصل به نشست جاری همان کاربر وردپرس، نگهداری می‌شود.

### پیکربندی الزامی

در فایل `wp-config.php` مقدار واقعی آدرس API را تعریف کنید (نمونه زیر را با آدرس واقعی سرویس جایگزین کنید):

```php
define('PARSIAN_OS_API_BASE_URL', 'https://YOUR-BACKEND-HOST/api/v1');
```

نشانی باید HTTPS باشد. افزونه در صورت نبودن این ثابت یا استفاده از HTTP، اتصال را رد می‌کند. هیچ رمز یا توکنی را در کد قالب، JavaScript، یا پیام عمومی قرار ندهید.

### مسیرهای REST داخلی وردپرس

- `POST /wp-json/parsian-finance/v1/backend/login` — ورود با نام کاربری و رمز مستقل Backend.
- `GET /wp-json/parsian-finance/v1/backend/session` — بررسی نشست و هویت Backend.
- `POST /wp-json/parsian-finance/v1/backend/password` — تغییر رمز اولیه/فعلی در Backend.
- `DELETE /wp-json/parsian-finance/v1/backend/logout` — حذف توکن نشست Backend.

این مسیرها به نشست معتبر وردپرس، nonce استاندارد REST و مجوز مشاهده پنل مالی نیاز دارند. حساب Backend باید فعال و دارای نقش `manager` یا `accountant` باشد؛ superuser Backend نیز مجاز است. مجوزهای واقعی عملیات مالی باید در endpointهای Backend با RBAC بررسی شوند و مجوز وردپرس جایگزین آن نیست.

### وضعیت و محدودیت فعلی

این commit فقط پل ورود و مدیریت نشست Backend را اضافه می‌کند. رابط مالی فعلی هنوز از جدول‌های محلی وردپرس می‌خواند/می‌نویسد؛ بنابراین تا تکمیل مرحله بعدی (تبدیل endpointهای مالی به proxy سمت سرور و انتقال منبع داده به Backend)، ورود موفق به Backend به معنی اتصال داده‌های مالی یا آماده‌بودن برای ثبت اطلاعات واقعی نیست. از داده آزمایشی استفاده کنید. تست زنده با سرور مقصد انجام نشده است.
