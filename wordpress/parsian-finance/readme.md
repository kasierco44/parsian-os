# افزونه مالی PARSIAN OS

**نسخه 0.3.0 — محیط آزمایشی / Staging**

این افزونه رابط وردپرس برای پنل مالی تأمین‌کنندگان PARSIAN OS است. منبع اصلی اطلاعات مالی، Backend مرکزی FastAPI است؛ جدول‌های قدیمی وردپرس فقط برای سازگاری باقی مانده‌اند و مسیرهای نوشتن محلی آن‌ها غیرفعال است.

## نصب
1. پیش از نصب، از فایل‌ها و پایگاه داده وردپرس نسخه پشتیبان کامل تهیه کنید.
2. از پیشخوان وردپرس به «افزونه‌ها ← افزودن ← بارگذاری افزونه» بروید و ZIP را بارگذاری کنید.
3. افزونه را فعال کنید. منوی «مالی پارسیان» ظاهر می‌شود.
4. برای کاربران وردپرس مجوز مشاهده پنل را از طریق نقش «مدیر مالی پارسیان» یا «حسابدار پارسیان» بدهید.
5. در `wp-config.php` آدرس API واقعی Backend را با HTTPS تعریف کنید:

```php
define('PARSIAN_OS_API_BASE_URL', 'https://YOUR-BACKEND-HOST/api/v1');
```

6. با کاربر وردپرس وارد پنل شوید و سپس با حساب مستقل PARSIAN OS Backend احراز هویت کنید. حساب Backend باید فعال و دارای نقش مدیر یا حسابدار باشد.
7. ابتدا فقط با حساب‌های آزمایشی و داده غیرواقعی، تمام عملیات را بررسی کنید.

## امکانات نسخه 0.3.0
- ورود مستقل Backend و نگهداری رمز توکن به‌صورت رمزنگاری‌شده در سمت سرور وردپرس، متصل به نشست کاربر وردپرس.
- بازاعتبارسنجی هویت Backend در هر درخواست پروکسی و محدودسازی مسیرها به allowlist.
- فهرست تأمین‌کنندگان، ثبت تأمین‌کننده و مشاهده مانده پرداختنی از Backend مرکزی.
- ثبت بدهی با انتخاب سرفصل مجاز، تاریخ فاکتور و سررسید.
- ثبت پرداخت نقدی، انتقال بانکی و چک؛ ثبت وضعیت پاس یا برگشت چک.
- ثبت مانده افتتاحیه فقط برای مدیر، با جلوگیری از ثبت تکراری برای همان تأمین‌کننده.
- داشبورد بدهی‌ها و گزارش پیش‌بینی سررسید پرداخت‌ها تا ۹۰ روز.
- جلوگیری از ثبت تکراری بدهی و پرداخت با Idempotency-Key.
- رابط فارسی و راست‌چین؛ مبلغ‌ها به ریال نمایش داده می‌شوند.

## مجوزها و کنترل‌های مالی
- مجوز Backend منبع نهایی تصمیم‌گیری است؛ نقش وردپرس به‌تنهایی اجازه عملیات مالی مرکزی نمی‌دهد.
- مدیر و حسابدار می‌توانند تأمین‌کننده، بدهی و پرداخت ثبت کنند.
- ثبت مانده افتتاحیه در Backend فقط برای مدیر مجاز است.
- چک صادرشده به‌عنوان تعهد چک پرداختنی ثبت می‌شود؛ وضعیت آن تا تأیید پاس‌شدن قابل تغییر است.
- مسیرهای قدیمی نوشتن در جداول محلی وردپرس با permission callback مسدود شده‌اند.
- ارتباط Backend فقط با HTTPS و اعتبارسنجی TLS انجام می‌شود؛ redirect غیرفعال است.
- توکن Backend به JavaScript یا مرورگر ارسال نمی‌شود.

## مواردی که هنوز پیش از بهره‌برداری واقعی لازم‌اند
- اتصال و آزمون زنده روی هاست واقعی با دو حساب مجزای مدیر و حسابدار.
- تطبیق و انتقال سوابق قدیمی وردپرس؛ هیچ داده قدیمی به‌صورت خودکار منتقل نشده است.
- بررسی تطبیق مانده افتتاحیه با دفترکل و تأیید نهایی مدیر مالی.
- آزمون end-to-end ثبت بدهی، پرداخت، چک پاس/برگشتی، مجوزها و بازیابی نسخه پشتیبان.
- بررسی نسخه PHP، تنظیمات HTTPS، آدرس واقعی Backend و دسترسی شبکه هاست.

**هشدار:** تا پایان این آزمون‌ها از ثبت اطلاعات مالی واقعی در نسخه آزمایشی خودداری کنید. موفقیت CI یا نصب افزونه به‌تنهایی به معنی تأیید عملیاتی یا حسابرسی مالی نیست.

## پیکربندی
- ثابت الزامی: `PARSIAN_OS_API_BASE_URL`
- نمونه مسیرهای داخلی وردپرس:
  - `POST /wp-json/parsian-finance/v1/backend/login`
  - `GET /wp-json/parsian-finance/v1/backend/session`
  - `POST /wp-json/parsian-finance/v1/backend/password`
  - `DELETE /wp-json/parsian-finance/v1/backend/logout`
  - `POST /wp-json/parsian-finance/v1/backend/proxy`

رمزها، کلیدها یا توکن‌های واقعی را در مخزن GitHub، فایل عمومی، اسکرین‌شات یا پیام عمومی قرار ندهید.
