# لایه آفلاین موبایل

- پایگاه داده محلی با SQLCipher رمزگذاری می‌شود؛ کلید تصادفی ۲۵۶ بیتی در Android Keystore از طریق SecureStore نگهداری می‌شود.
- هنگام اولین اجرای نسخه رمزگذاری‌شده، داده‌های نسخه قدیمی SQLite به پایگاه داده رمزگذاری‌شده منتقل می‌شوند. فایل قدیمی فقط پس از پایان موفق کپی حذف می‌شود؛ در صورت خطا، فایل قبلی دست‌نخورده باقی می‌ماند.
- Outbox عملیات دارای شناسه idempotency است و تا تأیید سرور حذف نمی‌شود. خطاها و تعارض‌ها در دستگاه باقی می‌مانند.
- داده‌های مشتری، وظایف، پیگیری‌ها و کاتالوگ محصول در cache پایدار نگهداری می‌شوند.
- کاتالوگ با cursor مستقل و فایل‌های نسخه‌دار دریافت می‌شود؛ دانلود ناقص باعث جلو رفتن cursor نمی‌شود.
- ورود آفلاین فقط برای دستگاهی ممکن است که قبلاً نشست معتبر و داده‌های لازم را دریافت کرده باشد. نصب تازه بدون اینترنت نمی‌تواند هویت کاربر را از سرور تأیید کند.
- ثبت پیش‌نویس آفلاین مجاز است؛ فاکتور قطعی، وصول، چک، گردش موجودی و مانده حساب تا تأیید سرور نهایی نمی‌شوند.
- SQLCipher به بیلد بومی نیاز دارد و در Expo Go فعال نیست. برای بررسی این قابلیت باید APK بومی جدید نصب شود.
