# لایه آفلاین موبایل

این لایه زیرساخت محلی را فراهم می‌کند: SQLite برای cache و Outbox پایدار، شناسه عملیات برای idempotency، cursor سرور برای pull و ثبت وضعیت conflict/failed. `src/api/sync.js` قرارداد پیشنهادی `/sync/push` و `/sync/pull` را مصرف می‌کند؛ این endpointها باید در Backend پیاده‌سازی شوند، بنابراین تا آن زمان sync واقعی فعال نیست.

`src/catalog/catalog.js` manifest کاتالوگ و دانلود فایل نسخه‌دار را مصرف می‌کند. API کاتالوگ و فضای ذخیره‌سازی خصوصی سرور هنوز باید ساخته و پیکربندی شوند.

نکته امنیتی: این نسخه هنوز رمزگذاری SQLCipher را فعال نکرده است. پیش از استفاده با داده واقعی، پیکربندی SQLCipher، ثبت و لغو دستگاه، سیاست انقضای داده آفلاین و تست امنیتی باید تکمیل شود. داده مالی قطعی نباید در حالت آفلاین ثبت شود.
