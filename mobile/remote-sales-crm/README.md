# پارسیان‌یار ویزیتور — CRM آفلاین اندروید

این اپلیکیشن React Native / Expo برای ویزیتورهای دورکار پارسیان قطعه است. نسخه فعلی شامل ورود سازمانی، فهرست و ثبت مشتری، پیگیری‌ها، وظایف، کاتالوگ محصول و زیرساخت صف آفلاین است.

## ساخت و نصب

برای توسعه و بررسی ظاهر می‌توان از Expo استفاده کرد؛ اما قابلیت SQLCipher در Expo Go فعال نیست. برای تست واقعی پایگاه داده رمزگذاری‌شده باید APK بومی را بسازید و نصب کنید.

دستورهای ساخت: `npm install`، سپس `npx expo prebuild --platform android` و در پوشه `android` اجرای `./gradlew assembleDebug`.

Workflow گیت‌هاب نیز APK نوع Debug را می‌سازد و به‌عنوان Artifact منتشر می‌کند.

## اتصال API

متغیر محیطی `EXPO_PUBLIC_API_BASE_URL` باید نشانی کامل API با پیشوند نسخه باشد؛ قالب نمونه: `https://api.example.com/api/v1`.

برای ساخت APK در GitHub، در Repository Settings → Secrets and variables → Actions → Variables، متغیر `PARSIAN_API_BASE_URL` را با نشانی واقعی HTTPS تنظیم کنید. این نشانی نمونه، سرور واقعی نیست.

## قابلیت‌های پیاده‌سازی‌شده

- ورود سازمانی و تغییر اجباری رمز موقت
- ذخیره توکن در SecureStore
- فهرست مشتریان از API و cache محلی
- ثبت مشتری در حالت آفلاین با شناسه مستقل
- ثبت و تکمیل پیگیری‌ها و وظایف در SQLite و Outbox
- ارسال مجدد خودکار صف پس از بازگشت اتصال
- نگهداری و نمایش تعارض‌های همگام‌سازی
- کاتالوگ نسخه‌دار محصولات و ذخیره تصاویر برای مشاهده آفلاین
- رمزگذاری SQLCipher و انتقال داده‌های نسخه قدیمی SQLite به پایگاه داده رمزگذاری‌شده

## محدودیت‌های مهم

- نصب تازه بدون اینترنت نمی‌تواند حساب کاربر را احراز هویت کند؛ ورود آفلاین فقط برای دستگاهی ممکن است که قبلاً نشست معتبر و داده‌های لازم را دریافت کرده باشد.
- پیش‌فاکتور، فاکتور نهایی، وصول، چک، موجودی و پورسانت هنوز به چرخه کامل عملیاتی و مالی متصل نشده‌اند.
- پایگاه داده آفلاین سرور، گزارش‌گیری کامل، مدیریت دستگاه‌ها و صفحه رفع تعارض هنوز نیازمند تکمیل و آزمون پذیرش هستند.
- SQLCipher به APK بومی نیاز دارد؛ اجرای این لایه در Expo Go آزمون معتبر رمزنگاری محسوب نمی‌شود.

تا قبل از استقرار Backend واقعی، اجرای Migrationها، تنظیم HTTPS و گذراندن آزمون‌های قطع/وصل اینترنت، از اطلاعات مالی و مشتریان واقعی در این نسخه استفاده نکنید.
